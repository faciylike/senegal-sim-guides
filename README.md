**<span id="运营商">1. 主流运营商：三足鼎立，各有千秋</span>**
*   **Orange Sénégal：** 老大哥，覆盖广得像达喀尔街头的“七座小巴”（Tata Sumo），尤其偏远地区优势明显。网络稳定性口碑最好，但套餐价格嘛... 有时也像它的品牌色，有点“热”（贵）。2025年依然是商务人士和需要跑外地的首选。想象一下在圣路易的渔村还能流畅视频通话？
*   **Free Sénégal：** 搅局者，靠低价套餐杀出重围，像当地市场里吆喝最响亮的摊贩。在达喀尔等大城市，网速快得飞起，刷TikTok、看球赛直播很爽。不过，一出核心城区，信号可能就跟你玩“捉迷藏”了。预算有限、主要在城市的背包客最爱。
*   **Expresso Sénégal：** 本地力量，深耕市场多年，有点像亲切的街角小店。套餐设计灵活，常有针对特定社群（学生、某地区居民）的优惠。覆盖和网速介于前两者之间，胜在性价比和本地化服务。有没有遇到过店员耐心教你设置、还送你小礼物的？Expresso的线下店有时会。

**<span id="套餐">2. 2025套餐价格：从“聊个天”到“刷不停”</span>**
　　价格这东西，跟玫瑰湖的水位一样，每年都有波动（2025年9月参考）：
*   **纯流量包（主流）：**
    *   **小胃口（1-3天/少量应急）：** 500MB - 1GB，约 500 - 1000 XOF (≈ 0.8 - 1.6 USD)。买瓶水的钱，够发定位查地图了。
    *   **中等需求（1周/常规使用）：** 3GB - 10GB，约 2000 - 5000 XOF (≈ 3.3 - 8.2 USD)。刷社交媒体、查邮件、偶尔导航，稳稳当当。
    *   **大流量（1月/重度依赖）：** 15GB - 无限量（通常高速流量后限速），约 7000 - 15000 XOF (≈ 11.5 - 24.6 USD)。追剧党、远程工作者的“续命包”。
*   **通话+短信+流量组合包：** 通常比纯流量包贵一些，本地通话分钟数充足（如1000分钟+5GB流量，约8000 XOF）。常联系本地朋友或办事需要打电话的，这个更划算。
*   **日租卡/旅游卡：** 部分运营商提供，价格稍高但省心（如 1500 XOF/天 无限量，限速阈值较低）。适合超级短期或怕麻烦的人。

**<span id="设置">3. 关键设置：APN与频段，信号满格的钥匙</span>**
　　买卡不设置？等于给车加了油却拔了钥匙！店员通常会帮你，但自己懂更安心：
*   **APN（接入点名称）：** 这是手机连接运营商网络的“门牌号”。2025年主流设置：
    *   **Orange:** `internet.orange.sn` (新卡常用) 或 `orange.sn`
    *   **Free:** `free`
    *   **Expresso:** `expresso`
    *   *(小贴士：拿到卡插入后，运营商会自动下发配置短信，点击链接安装最准！没收到？手动输入上述APN试试，用户名密码通常留空或填`free`/`expresso`)*
*   **网络频段：** 塞内加尔主要用 **3G (UMTS 900/2100)** 和 **4G LTE (Bands 3, 7, 20)**。Band 20 (800MHz) 像宽敞的国道，覆盖远穿透强，对偏远地区信号至关重要！出发前瞄一眼自己手机支持哪些频段（特别是Band 20），兼容性更好。5G？2025年在达喀尔核心区有试点，但普及度还远不如4G。

**<span id="合规">4. 实名制：2025年必须跨过的门槛</span>**
